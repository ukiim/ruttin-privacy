# 루띤 개인정보 처리방침

[루띤(Ruttin)](https://apps.apple.com/) 앱의 개인정보 처리방침 페이지입니다.
한국어·English·日本語·简体中文 4개 언어를 담고 있으며, GitHub Pages로 서비스합니다.

- `index.html` — 자체 완결형 단일 파일 (외부 리소스 없음)
- 언어 지정: `?lang=en` 또는 `#en` (`ko` / `en` / `ja` / `zh`)

원본은 앱 저장소의 `docs/privacy-policy.html`이며, 내용을 고칠 때는 두 곳을 함께 맞춘다.
